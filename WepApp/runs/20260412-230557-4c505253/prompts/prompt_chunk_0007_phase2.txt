### WHAT IS AN ONTOLOGY RELATION?
An ontology relation (object property) defines a typed semantic link between two class types. The DOMAIN is the subject class; the RANGE is the object class. Think: 'Every instance of [domain] can be linked via [relation] to an instance of [range].' Relations model the SCHEMA of the domain, not individual facts.
Example: 'has monitoring data(Patient → Monitoring Data)' means every Patient can have Monitoring Data associated with them.

### RELATION EXTRACTION METHOD (Chain-of-Thought)
For each pair of known classes, reason step by step:
1. Do these two classes co-occur or interact in the text?
2. What is the SEMANTIC NATURE of their link? (measurement, treatment, assessment, outcome, composition, causation, etc.)
3. Which class is the subject (domain) and which is the object (range)?
4. Assign a descriptive relation label from the patterns below, or create a meaningful label if none fits.
5. Find an exact text quote that supports this relationship.
