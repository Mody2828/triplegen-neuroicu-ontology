### WHAT IS AN ONTOLOGY RELATION?
An ontology relation (object property) defines a typed semantic link between two class types. The DOMAIN is the subject class; the RANGE is the object class. Think: 'Every instance of [domain] can be linked via [relation] to an instance of [range].' Model the SCHEMA, not individual facts.

### RELATION EXTRACTION METHOD (Chain-of-Thought)
For each pair of classes in the ontology, reason step by step:
1. Do these classes co-occur or interact in the text?
2. What is the semantic nature of their link?
3. Which class is domain (subject) and which is range (object)?
4. Assign a relation label from the patterns below, or create one.
5. Find an exact text quote as evidence.
